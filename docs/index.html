Transfer a file

  1. Install the PocketPort Mac helper.
  2. Connect both devices to the same trusted Wi-Fi network. In Terminal, run pocket-port followed by the file’s path.
  3. Open PocketPort, tap Scan, and scan the QR code displayed on your Mac. Allow Camera and Local Network access when prompted.
  4. After Saved offline appears, reopen the file anytime from the app’s Files list.

Get help

If a QR code expires, rerun the Mac command to generate a fresh one. If the phone cannot connect, check that both devices are on the same network and that PocketPort has Local Network access.

Contact PocketPort support on GitHub. Issues are public. Leave out private files, QR codes, and transfer links.
