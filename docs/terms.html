Using PocketPort

Use PocketPort only to transfer files you own or have permission to access and share. Follow applicable law and the rules for the devices and networks you use.

Install the Mac helper from the PocketPort repository. Use a trusted local network and keep QR codes and transfer links private.

Transfers and copies

PocketPort saves an offline copy of each successful import. Keep the original or a backup of important files before removing a copy from any device. A file exported through the system share sheet is handled by the destination you choose.

Transfers depend on compatible devices, supported file formats and sizes, available storage, and a working local network. If a transfer fails, you can retry with a fresh share code from your Mac.
